# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 我的实践体会

虽然本次实践不要求开发真实后端，但在编写这个 API 文档示例时，我学习了如何在 Markdown 中优雅地插入 JSON 代码块。使用 `mkdocs-material` 主题时，代码块不仅会自动高亮，还能显示行号，这让文档看起来非常专业。
