# 关于本项目

## 项目目标

实现从 Markdown 文档到公开网站的自动化发布。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容 |
| MkDocs Material | 将文档构造成静态网站 |
| GitHub Actions | 自动执行安装、构建和部署 |
| GitHub Pages | 托管并提供网站访问地址 |

## 我的实践体会

通过这次实践，我理解了源码和构建产物的关系。`docs/` 目录存放的是纯文本的源码，而最终用户看到的是由 MkDocs 生成的 `site/` 静态网页。配置 `mkdocs.yml` 时，YAML 格式对空格缩进要求极高，稍不注意就会报错，这让我养成了写代码时严谨的习惯。
